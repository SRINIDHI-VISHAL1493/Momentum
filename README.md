# Momentum

A frontend-first study planning dashboard built for the Frontend Web Development Hackathon 2026.

## The problem

Students often manage fragmented deadlines, study plans, and focus time across several tools. Momentum brings a daily task queue, light prioritisation, meaningful progress feedback, and a distraction-free focus timer into one fast, browser-based experience.

## Features

- Add, complete, filter, and delete tasks
- Persistent local storage — no account or backend required
- Smart high-priority and today filters
- 25-minute focus timer with pause/resume
- Responsive, keyboard-friendly interface for desktop and mobile
- Clear visual hierarchy, semantic markup, accessible labels, and reduced visual clutter

## Technology

Vanilla JavaScript, semantic HTML, and modern CSS. No framework, backend, build dependency, or account is required.

## Run locally

```bash
npm run dev
```

Create a deployment-ready static bundle with `npm run build`.

## Suggested demo flow

1. Introduce Momentum as a single, calm workspace for student priorities and focus.
2. Add a real task and assign its due date, priority, and estimated duration.
3. Filter to **High priority**, complete a task, and show the live progress update.
4. Start, pause, and resume the focus timer.
5. Resize to a phone viewport to show the responsive navigation and layout.

## Deployment

The `dist/` folder created by `npm run build` is a plain static site. Upload it to Netlify, Vercel, Cloudflare Pages, or GitHub Pages. No environment variables or server configuration are needed.
